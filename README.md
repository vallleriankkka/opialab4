# Домашнее задание к работе 4
## Условия задания
14. Калибровка станка
Три важнейших параметра станка (A, B, C) должны быть идеально отлажены. Система калибровки выдает сообщение об успехе, если каждое из значений параметра кратно трем. Запишите условие успешной калибровки
### Контрольный пример 1
```
A = 3, B = 6, C = 9
Калибровка успешна
```
### Контрольный пример 2
```
Входные данные:
A = 10, B = 2, C = 3
Калибровка не удалась
```
## 1. Алгоритм и блок-схема
### Алгоритм:
1. Начало
2. "Для успешной калибровки каждый параметр должен быть кратен трём"
3. "Введите три параметра для калибровки"
4. Ввод A, B, C
5. (A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0)\
   Да: Калибровка успешна\
   Нет: Калибровка не удалась
6. Конец

```c
#include <locale.h>
#include <stdio.h>

int main()
{
	setlocale(LC_CTYPE, "");

    //Контрольный пример 1

    //Калибровка успешна

     //Контрольный пример 2
    //A = 10, B = 2, C = 3
    //Калибровка успешна

    int A, B, C;
    int result;
    printf("Для успешной калибровки каждый параметр должен быть кратен трём\n");
    printf("Введите три параметра для калибровки через запятую: \n");
    scanf("%d, %d, %d", &A, &B, &C);


    result = ((A % 3 == 0) && (B % 3 == 0) && (C % 3 == 0));

    result && printf("Калибровка успешна\n");
    !result && printf("Калибровка не удалась\n");

    return 0;
}
```
